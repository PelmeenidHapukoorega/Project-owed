# Building a job mail sorter on top of Proton Mail Bridge

## Intent

I wanted to sort my job-related mail from Proton Mail into folders, using a local Proton Mail Bridge and Python scripts [E083, E089, E157, E221]. The folders include confirmations, rejections, noise and a progress folder for later rounds [E154, E157, E177, E185]. The bridge runs natively with systemd, not docker, "because no official image and it handles my decrypted mail" [E011]. It "needs pass with passphrase-free gpg key so the server login is the protection" [E012]. I also kept a build log and README in the repo as I went [E009, E021, E108, E230]. The last README commit mentions "the new direction of the project", but the events don't say what that direction is [E230].
